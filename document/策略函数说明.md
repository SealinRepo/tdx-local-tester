# 策略框架与内置函数说明

## 回测入口与交易时序

页面回测采用多标的模式，不需要在表单指定单个代码。脚本必须定义 `Strategy` 类，并实现同步方法 `on_day(self, day, broker)`。`day` 是 `YYYY-MM-DD` 格式的交易日字符串；`broker` 是账户和交易接口。策略在每个交易日收盘后运行一次。

- **下一交易日开盘价**（推荐）：策略当天提交的委托在下一交易日开盘撮合。回测区间最后一天提交的委托不会成交。
- **当日收盘价**：策略当天提交的委托按当天收盘价撮合，有前视风险。
- 成交量和历史行情只来自本地通达信数据。组合回测按需读取证券数据；建议限制代码列表，不要在每个交易日读取整个股票池。
- 委托受回测配置中的佣金、最低佣金、印花税和滑点影响。A 股按每手 100 股处理；不模拟涨跌停、停牌成交、分红及拆并股。

```python
class Strategy:
    def __init__(self):
        self.watchlist = ["600036", "000001"]

    def on_day(self, day, broker):
        quotes = get_history(self.watchlist, 21)
        for code in self.watchlist:
            history = quotes.get(code, [])
            if not history:
                continue
            latest = history[0]  # 列表第一项是当日，第二项是上一交易日
            position = broker.get_position(code)
            if latest["C"] > 0 and position["size"] == 0:
                broker.buy(code, broker.get_cash() * 0.1)
```

## 股票池和行情

### `get_stock_codes() -> list[str]`

无参数。返回通达信本地证券目录中识别为沪深北普通 A 股的代码，排除 B 股、基金、指数及债券等非普通股。分类依据是索引所属市场与证券代码段；名称以“退市”“退”或“摘牌”开头的记录会被排除。名称索引没有统一可靠的上市状态字段，因此无法保证识别所有已退市但名称未更新的证券。返回代码不保证都有回测区间内的日线数据。

```python
codes = get_stock_codes()
watchlist = [code for code in codes if code.startswith("60")]
```

### `get_stock_names(codes: list[str] | None = None) -> list[dict[str, str]]`

| 参数 | 说明 |
|---|---|
| `codes` | 可选的股票代码字符串数组；必须是列表或元组。省略或传入 `None` 时，返回本地目录中识别为沪深北普通 A 股的全部证券；提供数组时，非普通 A 股或未知代码会被忽略，结果按输入顺序返回，输入中重复的有效代码也会重复返回。 |

返回元素包含 `code` 和 `name` 两个字段。

```python
all_stocks = get_stock_names()
for stock in all_stocks:
    print(stock["code"], stock["name"])

stocks = get_stock_names(["600036", "000001", "not-found"])
# [{"code": "600036", "name": "招商银行"}, {"code": "000001", "name": "平安银行"}]
for stock in stocks:
    print(stock["code"], stock["name"])
```

### `get_history(codes: list[str], count: int) -> dict[str, list[dict]]`

| 参数 | 说明 |
|---|---|
| `codes` | 要查询的证券代码字符串数组；必须是列表或元组。代码必须存在于本地股票目录中；未知代码会抛出 `ValueError`。重复代码只查询和返回一次。空数组返回空字典。 |
| `count` | 每只证券最多返回的最近行情条数；必须是大于 0 的整数，布尔值不接受。 |

返回以证券代码为键的字典。每个值是该代码最多 `count` 条日线记录，**按日期从新到旧排列**，第一条为当前日期可用的最新行情。数据范围从回测开始日期至当前 `day`，不包括回测开始日前的数据；证券在某日无行情时，该日不会出现在它的数组中。无可用历史时，该代码对应空数组。

历史数组支持按相对交易日访问：`history[0]` 是最新一条，`history[-1]` 是它之前最近一条，`history[-2]` 再往前一条，以此类推。负索引表示向过去偏移，不使用 Python 列表原生的“从末尾倒数”含义。证券停牌或缺少行情时，偏移按该证券实际返回的历史记录计算。

每条记录包含：

| 字段 | 含义 | 单位/格式 |
|---|---|---|
| `date`、`日期` | 交易日期 | `YYYY-MM-DD` |
| `O` | 开盘价 | 元 |
| `C` | 收盘价 | 元 |
| `H` | 最高价 | 元 |
| `L` | 最低价 | 元 |
| `V` | 成交量 | 通达信行情文件中的成交量单位 |

```python
quotes = get_history(["600036", "000001"], 20)
history = quotes["600036"]
if len(history) >= 2:
    today_close = history[0]["C"]
    yesterday_close = history[-1]["C"]
    today_volume = history[0]["V"]
```

## 账户查询

### `broker.get_cash() -> CashInfo`

无参数。返回一个可直接参与数值运算的现金信息对象（数值部分等于可用现金），兼容原有 `broker.get_cash() * 0.9` 等用法。对象包含以下字段，单位均为元：

- `total`：账户总权益，即可用现金加已载入行情的持仓市值。
- `available`：当前可用现金；待成交买单尚未扣款，不冻结现金。

```python
cash = broker.get_cash()
buying_power = cash.available
equity = cash.total
broker.buy("600036", cash * 0.9)
```

### `broker.get_position(code: str | None = None) -> dict`

| 参数 | 说明 |
|---|---|
| `code` | 可选，要查询的证券代码。多标的 `on_day` 策略必须显式传入；旧式单标的策略省略时使用当前标的。 |

返回 `symbol`、`size`、`sellable_size`、`average_cost`、`market_value`、`unrealized_pnl`：

- `size`：持有股数。
- `sellable_size`：遵循 A 股 T+1 后当前可卖股数，当日买入的股票不可卖。
- `average_cost`：按买入成交股数加权的持仓成本，买入佣金计入成本；部分卖出后按已实现盈亏调整剩余持仓成本（盈利降低成本、亏损提高成本，卖出佣金和印花税计入盈亏），清仓后归零。
- `market_value`：按最新可用收盘价计算的持仓市值，单位为元。
- `unrealized_pnl`：按最新可用收盘价和平均成本估算的未实现盈亏，单位为元。

无持仓时仍返回该结构，股数和金额为 `0`。查询前可先调用 `get_history([code], 1)`，以载入当前日期的行情。

```python
position = broker.get_position("600036")
if position["sellable_size"] > 0:
    print(position["average_cost"], position["unrealized_pnl"])
```

### `broker.get_positions() -> dict[str, dict]`

无参数。返回所有当前非零持仓，键为证券代码，值与 `get_position(code)` 的持仓结构相同；空仓证券不出现在结果中。

```python
for code, position in broker.get_positions().items():
    print(code, position["size"], position["market_value"])
```

### `broker.get_equity(price: float | None = None) -> float`

| 参数 | 默认值 | 说明 |
|---|---|---|
| `price` | `None` | 兼容单标的策略的估值价格；多标的策略不要传此参数。 |

返回总权益，即可用现金加持仓市值，单位为元。多标的策略按已载入的最新收盘价估值；尚未载入行情的持仓暂按 `0` 市值计算，因此建议先查询持仓对应的行情。旧式单标的策略可以用 `price` 指定当前持仓估值价；不传时使用当前 bar 收盘价。

```python
get_history(list(broker.get_positions()), 1)
equity = broker.get_equity()
```

## 多标的交易委托

### `broker.buy(code: str, funds: float) -> None`

| 参数 | 说明 |
|---|---|
| `code` | 本地股票目录中存在且当前有可用行情的证券代码。 |
| `funds` | 计划投入金额，单位为元；必须是大于 `0` 的有限数值。 |

按当前可用收盘价换算股数并向下取整为 100 股的整数倍，再提交委托。若金额不足一手会抛出 `ValueError`。下一交易日开盘成交时，若开盘价、滑点和费用导致现金不足，系统会继续减少整手数量；无法买入一手则不成交。实际成交股数和成本以成交记录为准。

```python
if broker.get_cash() >= 5000:
    broker.buy("600036", 5000)
```

### `broker.sell(code: str, funds: float | None = None) -> None`

| 参数 | 说明 |
|---|---|
| `code` | 本地股票目录中存在且当前有可用行情的证券代码。 |
| `funds` | 可选，计划卖出金额，单位为元；提供时必须是大于 `0` 的有限数值。省略或传入 `None` 时卖出全部可卖持仓。 |

提供 `funds` 时，在实际成交价格下换算股数并向下取整为 100 股的整数倍；数量不会超过可卖持仓。省略金额时卖出全部可卖持仓；若剩余持仓不足整手，则清仓时可以一次性卖出零股。遵循 T+1，当日买入的股票不可当日卖出。

```python
position = broker.get_position("600036")
if position["sellable_size"] >= 100:
    broker.sell("600036", 5000)  # 按约 5000 元卖出，成交数量仍受持仓和整手限制
# 清仓：broker.sell("600036")
```

### `broker.cancel_all() -> None`

无参数。取消当前全部尚未成交的委托；已成交委托不会被撤销。

```python
broker.cancel_all()
```

## 单标的兼容接口

旧式单标的 `on_bar(self, bar, broker)` 策略从回调参数 `bar` 直接读取当前行情字段（`date`、`open`、`high`、`low`、`close`、`volume`）；历史序列可从 `broker.history` 获取，类型为按时间从旧到新的 `Bar` 列表。新的多标的策略统一使用 `get_history(codes, count)`。

```python
def on_bar(self, bar, broker):
    closes = [item.close for item in broker.history]
    if bar.close > 0 and closes:
        print(bar.date, bar.close)
```

### `broker.buy(size: int) -> None` 与 `broker.sell(size: int | None = None) -> None`

兼容旧式单标的接口，参数 `size` 是股数而不是金额，买入数量须为正的 100 股整数倍。卖出省略 `size` 表示卖出全部可卖持仓；指定数量须为正整数倍的 100 股，或等于全部持仓以清仓。多标的 `on_day` 中请勿使用这两个旧签名。

```python
broker.buy(200)    # 买入 200 股
broker.sell(100)   # 卖出 100 股
broker.sell()      # 卖出全部可卖持仓
```

### `broker.order_value(value: float) -> None`

| 参数 | 说明 |
|---|---|
| `value` | 当前标的计划买入金额，单位为元；必须是正有限数值。 |

按当前收盘价换算成 100 股整数倍后提交买单，现金不足时会减少成交数量。仅用于旧式单标的回测。

```python
broker.order_value(broker.get_cash() * 0.5)
```

### `broker.order_target_value(value: float) -> None`

| 参数 | 说明 |
|---|---|
| `value` | 当前标的目标持仓市值，单位为元；必须是非负有限数值。 |

按当前收盘价换算目标股数，提交与当前持仓之间的差额委托；目标为 `0` 时尝试清仓。仅用于旧式单标的回测。

```python
broker.order_target_value(20_000)
```

### `broker.order_target_percent(percent: float) -> None`

| 参数 | 说明 |
|---|---|
| `percent` | 当前标的目标仓位占账户权益比例，范围为 `0` 至 `1`（含边界）。 |

以账户权益乘以比例作为目标持仓市值，再按 `order_target_value` 规则调仓。仅用于旧式单标的回测。

```python
broker.order_target_percent(0.5)  # 目标将一半账户权益配置到当前标的
```

## 指标函数

指标函数输入的序列按时间从旧到新排列。数值单位由输入决定，例如传入收盘价就返回价格指标。

### `sma(values: list[float], period: int) -> float | None`

| 参数 | 说明 |
|---|---|
| `values` | 按时间从旧到新的数值序列。 |
| `period` | 窗口长度，必须是正整数。 |

返回最近 `period` 个值的算术平均；历史长度不足时返回 `None`。

```python
average = sma([10, 11, 12, 13], 3)  # 12.0
```

### `ema(values: list[float], period: int) -> float | None`

参数含义及周期限制与 `sma` 相同。先以首个 `period` 值的简单平均作为初值，再依次使用平滑系数 `2 / (period + 1)` 更新；历史长度不足时返回 `None`。

```python
average = ema([10, 11, 12, 13], 3)
```

### `cross_up(fast, slow) -> bool`

| 参数 | 说明 |
|---|---|
| `fast` | 快线当前值，或按时间从旧到新的数值序列。 |
| `slow` | 慢线当前值，或按时间从旧到新的数值序列；须与 `fast` 使用相同类型。 |

两个参数为序列时，最近至少各有两个值，且上一时点 `fast <= slow`、最新时点 `fast > slow` 时返回 `True`，表示本期发生金叉；否则返回 `False`。两个参数为数值时，返回当前快线是否高于慢线，即 `fast > slow`；单个时点的数值无法单独判断是否刚发生穿越。

```python
# 用两期均线值检测是否刚刚金叉
if cross_up([9.8, 10.2], [10.0, 10.1]):
    print("本期发生金叉")

# 只比较当前快慢线的相对位置
if cross_up(10.2, 10.1):
    print("快线当前高于慢线")
```

### `cross_down(fast, slow) -> bool`

参数类型及含义与 `cross_up` 相同。两个参数为序列时，上一时点 `fast >= slow` 且最新时点 `fast < slow` 返回 `True`，表示本期发生死叉；昨日两线相等也会触发下穿。序列任一不足两个值时返回 `False`。两个参数为数值时，返回 `fast < slow`，只表示当前快线低于慢线。混用数值与序列会抛出 `TypeError`。

```python
fast = [9.8, 10.2]
slow = [10.0, 10.1]
if cross_up(fast, slow):
    print("发生金叉")

fast = [10.2, 9.8]
slow = [10.0, 10.1]
if cross_down(fast, slow):
    print("发生死叉")
```

## 完整示例：均线金叉买入、死叉卖出

本示例在每个交易日读取自回测开始以来的历史数据，使用 5 日与 20 日均线交叉信号。均线序列须先反转成由旧到新；行情数组本身仍是新日期在前。

```python
class Strategy:
    def __init__(self):
        self.watchlist = ["600036", "000001"]

    def on_day(self, day, broker):
        quotes = get_history(self.watchlist, 21)
        for code in self.watchlist:
            history = quotes.get(code, [])
            if len(history) < 21:
                continue

            closes = [bar["C"] for bar in reversed(history[:21])]
            fast = [sma(closes[:i], 5) for i in range(5, len(closes) + 1)]
            slow = [sma(closes[:i], 20) for i in range(20, len(closes) + 1)]
            if len(fast) < 2 or not slow:
                continue

            position = broker.get_position(code)
            if cross_up(fast, slow) and position["size"] == 0:
                broker.buy(code, broker.get_cash() * 0.1)
            elif cross_down(fast, slow) and position["sellable_size"] > 0:
                broker.sell(code)
```

> 信号按收盘数据计算。使用推荐的下一交易日开盘成交模式，可避免用当日收盘价同时生成信号并成交。
